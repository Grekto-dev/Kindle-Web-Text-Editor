SOBRE ESTE EDITOR

Este é um editor de texto leve, desenvolvido para ser compatível com o navegador experimental do Kindle. Ele permite que você escreva, edite e acesse documentos a partir de qualquer dispositivo, sem necessidade de login ou instalação.

FUNCIONAMENTO GERAL

Todos os textos criados ou editados aqui são armazenados no servidor usando um sistema de identificação por código único de 6 caracteres (exemplo: AB123C). Esse código funciona como a "chave" para recuperar ou continuar um documento salvo anteriormente — tanto no Kindle quanto em um computador ou celular.

COMO FUNCIONA O SALVAMENTO

  • Ao clicar em "Salvar" pela primeira vez, um código é automaticamente gerado e exibido no topo da tela ("Código do Documento").
  • Esse código é o identificador único do seu documento. Guarde esse código com cuidado.
  • Nos salvamentos seguintes, o mesmo código será usado — o conteúdo será sobrescrito no mesmo documento.

COMO ACESSAR UM DOCUMENTO EM OUTRO DISPOSITIVO

  • No computador ou celular: acesse o editor e clique em "Carregar", digitando o código salvo.
  • No Kindle: clique em "Carregar", digite o código, e o texto será recuperado do servidor.

COMO TRANSFERIR ARQUIVOS ENTRE DISPOSITIVOS

O sistema foi pensado para que você possa:

  • Criar um texto no PC e continuar no Kindle (ou o contrário).
  • Editar no Kindle e fazer o download no PC como backup.
  • Subir um texto do PC para o servidor e depois carregá-lo no Kindle.

Você pode usar três formas principais para isso:

  • Código do Documento: a forma mais prática, tudo fica salvo no servidor e acessível com o código.
  • Botão "Upload": envia um arquivo .txt ou .html do dispositivo local para o editor.
  • Botão "Download": salva o conteúdo do editor como arquivo .txt ou .html no dispositivo.

LIMITAÇÕES DO NAVEGADOR DO KINDLE

O navegador do Kindle não oferece suporte completo para upload ou download de arquivos. Por isso, essas funções funcionam melhor em navegadores modernos. No Kindle, recomenda-se sempre usar o sistema de código.

BOTÕES E FUNÇÕES DA INTERFACE

  • Novo: limpa o editor e começa um novo documento (sem código).
  • Salvar: salva o conteúdo atual no servidor.
  • Carregar: recupera um documento salvo anteriormente, com base no código.
  • Limpar: apaga o conteúdo atual do editor (com confirmação).
  • Download: exporta o conteúdo como arquivo .txt e/ou .html (uso recomendado em PC).
  • Upload: importa um arquivo .txt ou .html (apenas em navegadores modernos).
  • Deletar Documento: remove definitivamente o documento do servidor. Essa ação é irreversível.
  • Tema: alterna entre visual claro e escuro.
  • Idioma: alterna entre português e inglês.

AVISO DE SEGURANÇA

Esta é uma versão alfa do editor. Os arquivos não são armazenados com criptografia, e qualquer pessoa que possua o código do documento poderá acessá-lo. Guarde seu código com cuidado e use por sua conta e risco.

Atualizações com mecanismos de segurança serão incluídas futuramente. No momento, o foco está nas funcionalidades básicas do aplicativo.

ABOUT THIS EDITOR

This is a lightweight text editor designed to be compatible with the Kindle's experimental browser. It allows you to write, edit, and access documents from any device, without needing to log in or install any apps.

GENERAL FUNCTIONALITY

All texts created or edited here are stored on the server using a unique 6-character code (example: AB123C). This code works as a "key" to retrieve or continue a saved document — whether you're on a Kindle, computer, or mobile phone.

HOW SAVING WORKS

  • When you click "Save" for the first time, a code is automatically generated and shown at the top of the screen ("Document Code").
  • This code uniquely identifies your document. Keep it safe, as you will need it to load the document later.
  • Future saves will overwrite the document associated with this same code.

HOW TO ACCESS A DOCUMENT FROM ANOTHER DEVICE

  • On a computer or phone: open the editor and click "Load", entering your saved code.
  • On Kindle: click "Load", enter the code, and the text will be retrieved from the server.

HOW TO TRANSFER FILES BETWEEN DEVICES

This system is designed to let you:

  • Create a document on your PC and continue editing it on the Kindle (or the other way around).
  • Edit on the Kindle and download a backup on your PC.
  • Upload a document from your PC to the server and then load it on the Kindle using the code.

There are three main ways to do this:

  • Document Code: the simplest method. Everything is saved on the server and accessible from any browser using the code.
  • Upload: imports a .txt or .html file from your device into the editor.
  • Download: exports your text as a .txt or .html file to your device.

KINDLE BROWSER LIMITATIONS

The Kindle browser does not fully support file uploads or downloads. These functions work best on modern browsers. On Kindle, it is recommended to rely on the document code system for saving and accessing content.

INTERFACE BUTTONS AND FEATURES

  • New: clears the editor and starts a new document (without a code).
  • Save: saves the current content to the server. A code is created if it’s the first save.
  • Load: loads a previously saved document using its code.
  • Clear: erases the current content (a confirmation message is shown).
  • Download: exports the text as a .txt and/or .html file (works best on PC).
  • Upload: imports a .txt or .html file into the editor (only works on modern browsers).
  • Delete Document: permanently removes the document from the server. This action cannot be undone.
  • Theme: toggles between light and dark mode.
  • Language: switches between Portuguese and English.

SECURITY NOTICE

This is an alpha version of the editor. Files are not stored with encryption, and anyone who knows your document code can access its content. Keep your code secure and use this tool at your own risk.

Security mechanisms will be added in future updates. For now, the focus is on the app’s core functionality.
